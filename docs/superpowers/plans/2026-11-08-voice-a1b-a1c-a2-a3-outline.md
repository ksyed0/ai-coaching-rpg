## A1c (proposed US-0072): operations — `feature/EPIC-0003-US-0072-voice-operations`

> **Expanded into its own plan file (2026-11-09):** `docs/superpowers/plans/2026-11-09-voice-a1c-operations.md` (Tasks 0 to 15 in five batches, Resolved Facts R1 to R20, contradictions K1 to K11, the restart-budget decision). That plan supersedes the table below, which is kept for the record only; do not execute from it. The main changes against this table: a `services/voice-ops` package instead of `scripts/voice-*.sh|ts` (K1); `STT_URL` generated once into `.env` and reused (K2); no web `TRUST_PROXY` setting, the web `start` script binds loopback (K3); owner-supplied certificate files by default, the DNS-challenge path only after the owner names a provider (K4); Caddy forwards only `/rtc*` to LiveKit on its own TLS port (K6); a LiveKit outage, classified by control's own probe, no longer spends the restart budget (K7); `STT_MODEL_FILE` beside the `STT_MODEL` label (K9). Revision 2 of that plan (an independent review) adds: root scripts `pnpm -s --filter @acr/voice-ops run voice-<cmd>` (a bare `up` is pnpm's built-in `update`, K13); the STT request path is in whisper-server's argument list and guards only against browser-origin and DNS-rebinding requests (K14); Caddy stays in compose with a manual native fallback (K5); after a LiveKit outage participants rejoin by their own click (K15), and automatic rejoin moves to A3 row 5 below.
